# 01 — Retired templates

**What to build:** A template can be marked retired: it no longer shows in New space or in Help me choose, but spaces already made from it keep working exactly as before (views, reminder voices, money totals).

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] A retired template is absent from the gallery and from finder results
- [ ] An existing space made from a retired template still opens, reminds and counts in Money
- [ ] Tests cover both
