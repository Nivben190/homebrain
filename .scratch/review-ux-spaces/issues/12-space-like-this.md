# 12 — Make a space like this

**What to build:** From a space's settings, 'Make a space like this' creates a new space with the same layout, properties, icon and item titles (and routine schedules), without done states, notes, photos or values.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] New space has same view, schema and item titles
- [ ] No item data, photos or done states are copied
- [ ] Private spaces copy as private
