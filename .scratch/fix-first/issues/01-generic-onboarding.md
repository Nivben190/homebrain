# 01 — New homes get a setup that fits them

**What to build:** Someone starting a new home answers three quick questions — who lives here (just me / couple / family / roommates), any pets (dog, cat), any kids — and gets only the shared spaces that fit. Nobody gets the personal love notes written for one couple, a "Good words" space, or a Dog care space without a dog. The love note stays available as the existing opt-in "Morning love note" automation. After setup the person lands in "Help me choose". Joining an existing home keeps the personal starter (morning routine) only. Existing homes are untouched.

**Blocked by:** None — can start immediately.
