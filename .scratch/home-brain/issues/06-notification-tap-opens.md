# 06 - Tapping a notification always opens it

**What to build:** Tapping a push always lands on the run it was about: when the app is closed, already open on that page, open elsewhere, or open in a window the service worker doesn't control.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] If navigating an existing window fails, a new window opens on the run instead
- [ ] Tested on iPhone with the app closed, open in the background, and open on another screen
