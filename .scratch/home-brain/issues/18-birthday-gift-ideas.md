# 18 - Gift ideas on birthdays

**What to build:** Each date in a Reminders space (birthdays, anniversaries) can hold a list of gift ideas you jot down over the year. A week before the date, a push lists the ideas so you have time to buy one.

**Blocked by:** 10 - One table per space type, 11 - One reminder sender

**Status:** done — the existing "heads-up before" chips set how early (a week by default when chosen)
